# 杭电助手 · HDUHelper

面向杭州电子科技大学师生的 Android 校园应用，提供课表和一码通，支持 **Android 13 及以上版本**。

## 课程通知与小米超级岛

在“我的 → 通知设置”配置普通上课/下课提醒与提前分钟数。通知权限需要在系统中开启，可通过“测试通知”检查显示。

“自启动”和“电池优化”分别检测后台设置；电池优化同时展示 Android 豁免与小米省电策略。Xposed 用户可额外勾选“系统框架（system）”作用域、重启手机，再打开默认关闭的“Xposed 后台提醒增强”，减少系统对课程和日程闹钟的拦截与延迟。

HyperOS 3 用户可在 LSPosed（现代 API 101）启用杭电助手模块，勾选系统界面及其插件并重启作用域。授权后，通知设置才显示“开启课程表超级岛”；开启后以超级岛替代普通课程通知，未就绪时回退普通通知。超级岛内可开启上课静音，下课自动恢复；用户自行操作系统静音开关时，以用户选择为准。

## 功能

- **课表**：按周浏览、切换学期、查看课程详情；支持离线缓存，以及周末、教师、地点等显示设置。
- **日程**：管理个人日程、查看课程安排，并设置日程提醒。
- **一码通**：展示学校电子凭证二维码，支持自动与手动刷新，断网后重新联网或登录恢复时自动重试；展示时自动提高当前窗口亮度，离开后恢复。
- **账号**：数字杭电账号登录、自动恢复会话，以及需要额外验证时的官方网页登录。
- **外观**：跟随系统、浅色和深色主题。

底栏中的“应用”目前为占位页面。课表尚不支持独立实验模块、调休公告整合、手动编辑和导出；一码通不提供余额或充值功能。

## 下载与安装

前往 [最新正式版](https://github.com/KimmyXYC/HDUHelper/releases/latest)，下载附件中的 `HDUHelper-v版本号.apk`，在手机上打开并按系统提示允许安装。`SHA256SUMS` 可用于校验下载文件。

正式版与 CI 测试包使用同一固定签名；versionCode 相同或更高时可以覆盖安装并保留本地数据。CI 测试包位于 [GitHub Actions](https://github.com/KimmyXYC/HDUHelper/actions/workflows/ci.yml)，版本名形如 `v1.0.0.abcdefg`，末尾为源码提交 ID。

## 使用方法

1. 打开“我的”，点击“未登录”，输入数字杭电账号和密码；按需开启自动登录。学校要求验证码等额外验证时，按应用提示在官方页面完成。
2. 打开“课表”查看当前周，左右滑动切换周次，右上角切换学期，下拉手动刷新。点击课程查看完整周次、节次、校区、地点、教师和学分。
3. 在“我的 → 课表设置”调整课程显示及时间轴校区。首次读取成功后，课表会缓存到本机，离线也能查看；重新进入时先显示缓存，再尝试更新。
4. 打开“一码通”展示电子凭证，等待自动刷新或点击手动刷新。页面离开前台时会清除二维码，返回后重新获取；刷新失败时不会继续显示旧码。
5. 在“我的 → 外观设置”切换主题。退出账号会清除本应用的会话和课表缓存，不会注销学校其他系统中的登录。

仅通过官方网页登录且没有已验证密码时，应用只保存会话；需要密码自动登录时，请返回原生登录页重新验证。

## 隐私与安全

账号认证通过学校服务完成。登录资料与课表缓存使用 Android Keystore 加密保存在本机，并排除云备份和设备迁移；一码通二维码与业务 token 仅在内存中保存。应用不会读取官方网页中输入的密码。具体处理方式见 [技术说明](docs/architecture.md)。
