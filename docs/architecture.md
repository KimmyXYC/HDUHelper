# 架构与协议说明

## 代码组织

单个 Android 应用模块，`data/auth` 管理 CAS/SSO、会话存储与恢复；`data/campuscode` 管理一码通授权和签名；`data/timetable` 管理教务请求、解析和课表缓存。`data/settings` 和 `data/network` 管理设置与网络状态。`ui/HDUHelperApp.kt` 管理导航，ViewModel 持有界面状态，页面与共享组件位于 `ui/screens` 和 `ui/components`。

## 认证与存储

- 原生登录向 `sso.hdu.edu.cn` 提交 CAS 表单，每次重新获取 execution 和加密参数，按学校协议执行 AES/ECB 加密并通过 HTTPS 传输。身份以数字杭电 `loginInfo.rst` 的成功标识和有效账号为准，兼容 JSON/JSONP；HTTP 200 的登录页面不代表成功。
- 验证码检查 GET 也需要动态 `Csrf-Key` / `Csrf-Value` 头，缺少时可能 HTTP 200、业务码 401。生成规则有模拟回归测试。
- 密码、Cookie、必要个人资料和失败计数使用 Android Keystore AES-GCM 加密，存放于 `noBackupFilesDir`；课表使用独立密钥。官方 WebView 数据同样排除云备份和设备迁移。密码不进入可保存的页面状态。
- 启动、回前台和受保护请求失效时检查会话，优先复用 SSO，再尝试已保存密码。并发恢复合并，受保护 GET 最多重试一次，不增加周期后台任务。
- 连续三次明确凭据错误后清理会话；断网、超时和服务异常不计入。额外验证暂停自动提交，转由用户完成。取消、退出和换号会使旧操作失效，迟到回调不能恢复旧会话。
- 官方 WebView 不读取、注入或保存用户在网页中输入的密码。缺少同账号已验证密码时，网页登录只保存会话并关闭密码自动登录。退出仅清理本应用，不调用学校全局注销。

## 官方 WebView

使用手机 UA、手机 viewport 与 HTTPS。原生 View 宽高必须为 `MATCH_PARENT`，并启用官网 viewport；仅使用 Compose `fillMaxSize()` 仍可能保留原生 `WRAP_CONTENT`，造成视口异常与底部留白。公开页面回归检查手机布局、无横向溢出、填满视口及键盘弹出后的尺寸行为。

## 一码通

复用 SSO 授权，动态查找“电子凭证”应用并获取业务 token。签名兼容官方 MD5、SM3 与原始 SM2 协议，固定协议参数来自公开前端脚本；二维码由 ZXing 原样编码服务端字符串。

刷新间隔来自 `getFreshTime`，缺失或非正数时采用网页默认 300 秒。手动刷新不重置自动周期，并发请求合并；离开前台停止刷新并清码，返回立即获取。失败隐藏旧码，网络恢复后重试。业务 token 与二维码仅存内存，退出、换号时清理并拒绝迟到响应。窗口亮度仅在展示时提升，离开或进入后台恢复，不修改系统亮度。

余额读取同一用户信息接口 `/user-center/user-info` 的 `balance` 字段，单位为元，显示两位小数并随二维码刷新。缺失或无效值显示“余额暂不可用”，不影响二维码；余额随凭证仅保存在内存中。

## 课表

“应用 → 考试安排”使用独立 `ExamsViewModel`，复用教务数据源和考试缓存，独立维护所选学期，不受课表考试显示开关影响。页面前台每秒按校园时区计算下一场、进行中和已结束分组，后台停表，返回时立即重算；结束时间到达后归入底部灰色分组。时间无法确定的考试单独展示，不推测结束状态。

学期、校历和作息来自学校服务，不按自然月份猜测开学时间。进入时先读缓存、后台更新，保留正在浏览的周次；后台失败保留缓存，手动刷新才显示失败提示。

同一课程/教学班的全部安排合并判断结课。总览重叠依次优先本周课、最近未结课安排、已结课安排；局部重叠不扩大实际时间范围。详情可切换同时段其他排课，不受总览隐藏或显示设置影响。无法放入网格的课程及实践内容归入“其他安排”。

作息按课程校区分别获取；时间轴默认使用当前学期课程最多的校区，手动选择按账号与学期记忆，且不筛选课程。详情始终使用课程所属校区作息，缺失时显示“时间暂不可用”。

教务授权保留学校注册的 HTTP service 标识，实际回调通过 HTTPS 传输。业务 Cookie 仅存内存，最近成功的课表、校历和作息加密保存并按账号/学期隔离。失败保留缓存，退出或换号清理；HTTP 901、权限拒绝、未开放和真正空课表分别处理。

详细接口与解析边界见 [教务 SSO 与课表调研](jw-sso-timetable-analysis.md)，验证命令见 [开发文档](development.md)。
