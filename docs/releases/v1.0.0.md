# 杭电助手 v1.0.0

首个正式版本，支持 Android 13 及以上系统。

- 数字杭电账号登录、会话恢复与官方网页额外验证。
- 原生周课表、学期切换、课程详情、课表设置与加密离线缓存。
- 一码通电子凭证、自动和手动刷新、展示时提高窗口亮度。
- 跟随系统、浅色及深色外观。
- 正式 APK 启用 R8 代码优化、混淆和资源缩减，并使用固定发布签名；CI 包使用同一签名。

下载 `HDUHelper-v1.0.0.apk` 安装，`SHA256SUMS` 用于校验文件。此前安装的 Debug 包需要先卸载，卸载会清除本地登录资料、设置和缓存。

日程和应用页面仍为占位；课表暂不支持独立实验模块、调休公告整合、手动编辑、导出及提醒。一码通不包含余额或充值业务。
