# 杭电助手 v1.1.0

## 新功能

- 日程管理：新增、编辑与删除日程，支持重复规则、提醒和日期切换，并整合课表课程。
- 课程提醒：支持上课、下课提醒及提前时间设置，提供通知权限检查和测试通知。
- 在受支持的小米系统上，提供可选的 Xposed 后台提醒增强和课程表超级岛；需激活模块并勾选对应作用域。
- 课表设置自动获取校区选项，无需先打开课表；保留已选学期、周次和校区，并支持失败重试。
- 添加 AGPL-3.0 许可证；“关于应用”新增项目地址与开源协议说明。

## 改进与修复

- 一码通在网络恢复后自动重试，改善页面内的恢复体验。
- 根据系统支持情况隐藏小米省电策略及相关摘要；未勾选作用域时隐藏后台提醒增强。
- 修复后台增强的配置同步状态判断，等待模块确认生效；更新 APK 后检测旧模块并明确提示重启。

## 安装与升级

支持 Android 13 及以上系统。下载 `HDUHelper-v1.1.0.apk` 安装，`SHA256SUMS` 用于校验文件。正式 APK 使用与 v1.0.0 相同的发布签名，可覆盖升级并保留本地数据。

使用 Xposed 功能的用户，覆盖安装后请重启手机以加载新模块。后台提醒增强需要在 LSPosed 中勾选“系统框架”；课程表超级岛需要勾选系统界面及其插件（如有）。相关增强默认关闭，可在“我的 → 通知设置”中按需开启；普通通知提醒不依赖 Xposed。
