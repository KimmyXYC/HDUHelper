# 杭电助手 v1.1.1

## 新功能

- 新增应用更新检查：进入前台且联网时，每 24 小时最多自动检查一次 GitHub 最新正式版。
- “我的 → 关于应用”新增“检查更新”入口，可随时手动检查。
- 发现新版后显示版本号和更新说明，点击“前往下载”即可通过浏览器打开对应 Release 页面。

## 改进与修复

- 按版本号数字比较更新，兼容 CI 提交后缀，避免提示降级。
- 自动检查失败时保持安静；手动检查显示加载状态和结果。
- 修复深色模式下更新说明的文字颜色，移除“检查更新”下方的默认说明文字。

## 安装与升级

支持 Android 13 及以上系统。下载 `HDUHelper-v1.1.1.apk` 安装，`SHA256SUMS` 用于校验文件。正式 APK 沿用现有发布签名，可覆盖升级并保留本地数据。

使用 Xposed 功能的用户，覆盖安装后请重启手机以加载新模块。
