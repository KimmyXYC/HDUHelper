# 杭电助手 v1.2.0

## 新功能

- 应用页采用两列图标卡片布局，新增“考试安排”入口。
- 考试安排可独立选择学期，突出下一场考试并显示倒计时，支持进行中状态、考场、座号和详情查看。
- 已结束考试置灰并归入底部独立分组，按考试时间从早到晚排列；时间待定的考试单独展示。
- 日程和课表支持教务考试安排及详情，课表可单独控制考试显示，并支持考试提醒。
- 一码通新增余额显示，随二维码刷新。

## 改进与修复

- 两列考试卡片统一尺寸，适配长课程名、长考场信息和大字体；考试页内容统一左对齐。
- 日程增加上午、下午、晚上分隔，全天日程单独展示。
- 外观主题和作息校区选项改为右侧勾选、文字左对齐。
- 修复关于应用页的内容对齐和课表周次选择弹窗的显示问题。
- 日程和课表不再显示“该学期暂无考试安排”提示。

## 安装与升级

支持 Android 13 及以上系统。下载 `HDUHelper-v1.2.0.apk` 安装，`SHA256SUMS` 用于校验文件。正式 APK 沿用现有发布签名，可覆盖升级并保留本地数据。

使用 Xposed 功能的用户，覆盖安装后请重启手机以加载新模块。
