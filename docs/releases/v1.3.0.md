# v1.3.0

## 更新内容

- 将 Xposed 功能拆为独立的“杭电助手 Xposed”APK，独立维护版本。主应用更新不再需要重启系统界面或设备。
- 主应用通过受签名权限保护的接口读取模块状态、同步后台提醒增强开关；超级岛与后台增强继续使用原有宿主通道。
- 模块更新检测改为核对独立模块 APK，避免主应用更新后误报需要重启。

## 安装与迁移

- 主应用：`HDUHelper-v1.3.0.apk`，Android 13 及以上。
- 可选模块：`HDUHelper-Xposed-v1.0.0.apk`。仅使用普通功能时不必安装。
- 从旧版内置模块迁移：在 LSPosed 关闭旧“杭电助手”模块，启用“杭电助手 Xposed”，勾选所需作用域并重启一次。超级岛需要 `com.android.systemui` 和 `miui.systemui.plugin`；后台提醒增强需要系统框架 `system`。
- 后续只更新主应用无需重启；更新独立模块或更改作用域时，仍需重启对应宿主，系统框架需要重启设备。模块版本未变时无需重复安装。
- 两个 APK 使用相同正式签名；附件校验值见 `SHA256SUMS`。

## 验证

已在实体机验证后台增强开关同步、真实闹钟 Hook 和超级岛连接，并确认仅覆盖安装主应用后、不重启设备仍可通过上述测试。
