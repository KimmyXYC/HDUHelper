# v1.4.0

## 更新内容

- 新增原生考试成绩查询：按学期查看成绩、成绩分项与加权绩点，支持加密缓存和离线查看。计算结果仅供参考，以教务系统为准。
- 新增原生电费查询：复用统一认证登录，查看余额、近 14 天记录及日均消费，支持选择宿舍、绑定、更换和解绑电表。
- 新增三种桌面小组件，支持深浅外观、课程、考试和日程展示；普通 Android 小组件无需 Root 或 Xposed。
- 小米智能助理小组件中心接入可选 Xposed 模块，完善图标、预览与时间对齐。
- 课表设置中的“显示周末”拆为“显示周六”和“显示周日”，旧设置自动继承，单独显示周日时正确对齐日期和课程。
- 优化电费宿舍选择弹窗，使用独立单选行、可滚动列表和固定取消按钮。

## 安装与更新

- 主应用：`HDUHelper-v1.4.0.apk`，Android 13 及以上。
- 可选模块：`HDUHelper-Xposed-v1.1.0.apk`。本次模块版本独立升级，普通查询及标准 Android 小组件无需安装模块。
- 使用小米智能助理小组件中心时，需在 LSPosed 为“杭电助手 Xposed”启用“智能助理”（`com.miui.personalassistant`）作用域，更新模块后重启对应宿主；使用系统框架后台增强时请重启设备。
- 仅更新主应用无需重启。两个 APK 使用相同正式签名，附件校验值见 `SHA256SUMS`。

## 验证

- 201 项 JVM 测试通过；电费页面、长列表选择、课表独立周末开关、旧设置迁移及考试显示已通过设备测试。
- 真实账号统一认证、电费绑定状态、余额、历史和宿舍选项只读查询通过，测试未修改真实电表绑定。
