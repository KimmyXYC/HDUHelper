# v1.4.1

## 更新内容

- 课表周次选择中，选中周使用蓝色文字与浅蓝底，状态更清晰。
- 重叠课程及考试卡片右下角改为圆角折页标记，点击仍可查看重叠安排。
- 从其他页面或后台返回课表时保留此前浏览的学期和周次，冷启动回到当前周。
- 修复离线缓存、请求中断或失败重试后浏览周次被重置的问题。
- “返回当前周”保留静默更新，不再显示下拉刷新动画；手动下拉刷新保持原行为。

## 安装与更新

- 主应用：`HDUHelper-v1.4.1.apk`，Android 13 及以上。
- 可选 Xposed 模块维持 `v1.1.0`，已安装该版本的用户无需更新模块。
- 使用原有正式签名，可覆盖安装并保留数据；仅更新主应用无需重启。
- 附件校验值见 `SHA256SUMS`。

- 204 项 JVM 测试、Debug Lint、应用及设备测试 APK 构建通过。
