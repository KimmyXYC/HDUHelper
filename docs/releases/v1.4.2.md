# v1.4.2

## 更新内容

- 优化小米桌面小组件的留白，改善 logo 和日期过于贴近圆角边框的问题。
- 统一小米 2×2、4×2 和 4×4 卡片的内边距，保持安卓普通小组件原有布局。

## 安装与更新

- 主应用：`HDUHelper-v1.4.2.apk`，Android 13 及以上。
- 可选 Xposed 模块维持 `v1.1.0`，已安装该版本的用户无需更新模块。
- 使用原有正式签名，可覆盖安装并保留数据；仅更新主应用无需重启。
- 附件校验值见 `SHA256SUMS`。

## 验证

- 204 项 JVM 测试、主应用和 Xposed 模块的 Release 构建及 Lint、APK 分离检查通过。

- 小组件设备测试通过，覆盖三种卡片的深浅色、多种尺寸，以及空日程与已结束状态。
