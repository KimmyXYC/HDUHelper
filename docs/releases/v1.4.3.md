# v1.4.3

## 更新内容

- 修复 Xposed 模块已生效，但通知设置中两个开关因模块启动被拦截而不显示的问题。系统框架 Hook 现在会定向放行主程序到同签名模块的状态连接，模块无需手动开启自启动。
- 增强课程、考试和日程提醒：开启“Xposed 后台提醒增强”后，定向处理闹钟的待机、Doze、电池节能和后台启动限制；提醒到期时可通过系统通道临时唤醒被冻结的主程序。
- 增加模块连接失败提示和设置入口，补充连接恢复、请求身份校验与连续提醒测试。

## 安装与更新

- 主应用：`HDUHelper-v1.4.3.apk`，Android 13 及以上。
- 可选模块：`HDUHelper-Xposed-v1.2.0.apk`。使用 Xposed 增强功能的用户请同时更新主应用和模块，并重启手机加载新的系统 Hook。
- LSPosed 需勾选系统框架；超级岛另需系统界面与系统界面插件作用域。提醒增强仍由通知设置中的开关控制，通知与精确闹钟权限仍需开启。
- 使用原有正式签名，可覆盖安装并保留数据。附件校验值见 `SHA256SUMS`。

## 验证与适用范围

- 208 项 JVM 测试通过；主应用及模块的 Release 构建、Lint 和 APK 分离检查通过。
- 在 HyperOS `OS3.0.305.0.WOCCNXM`（Android 16）验证模块关闭自启动后的冷连接，以及主程序关闭自启动、开启 Android 电池优化时的两次冷启动与深度 Doze 提醒投递。课程、考试和两条日程通知均在各自目标时间后 10 秒内发布。
- 两个开关的实际显示、连接失败后的恢复、增强开关启停及伪造桥接请求拒绝测试通过。
- 适配及实机结果针对上述 ROM；其他 ROM、厂商极限省电与主动冻结场景仍需验证。关机、手动强行停止或模块未加载时不保证提醒投递。
